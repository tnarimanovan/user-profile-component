# 🎨 Profile Settings UI Challenge

Welcome to the **Profile Settings UI Challenge**! This repository provides a starting point for building an accessible, modern Profile Settings interface while evaluating the **vsc-accessibility-gamifier** VS Code extension.

As part of this challenge, we ask you to complete two short questionnaires:

1. **Before** starting, please complete the pre-task questionnaire.
2. **After** finishing the implementation, please complete the post-task questionnaire.

Your feedback will help us evaluate the usability and effectiveness of the **vsc-accessibility-gamifier** extension.

## 🎯 Objective

Your goal is to recreate the Profile Settings page using **Vue 3** (or pure HTML/CSS if preferred).

Throughout development, use the **vsc-accessibility-gamifier** extension to continuously evaluate your implementation. The extension provides live accessibility feedback, gamified achievements, and an accessibility score to help you build a WCAG-compliant interface.

Your objective is not only to match the design but also to achieve the highest possible accessibility score.

## 🚀 Getting Started

### 0. Complete Pre-Task Survey

### 1. Clone the repository

```bash
git clone git@github.com:tnarimanovan/user-profile-component.git
cd user-profile-component
```

### 2. Create your working branch

```bash
git checkout -b feature/your-name-profile-ui
```

### 3. Install dependencies

```bash
npm install
```

### 4. Install the VS Code extension

Clone or install the **vsc-accessibility-gamifier** extension and make sure it is enabled in VS Code before starting the challenge.

Repository:

<https://github.com/tnarimanovan/vsc-accessibility-gamifier>

### 5. Start the development server

```bash
npm run dev
```

## 📤 Submission & Exporting Results

Once you have completed the implementation and resolved as many accessibility errors as possible:

1. Open the **Mole's Burrow panel** in **VS Code**.

2. Click the **📥 Export & Save Study Report** (.json) button at the bottom of the sidebar to download your session results file (a11y-report-*.json).

3. Complete the Post-task questionnaire and upload your exported JSON file.
